# FocusFlow

AI destekli görev ve odaklanma asistanı.

## Özellikler
- Karanlık neon tema, glassmorphism
- Sürükle-bırak Kanban (Yapılacaklar / Yapılıyor / Tamamlandı)
- Öncelik etiketleri, düzenleme, tamamlama
- 25/5 Pomodoro, bildirim + ses
- Lo-Fi / yağmur ortam sesi
- Mock AI performans koçu
- localStorage kalıcılığı (Supabase/Firebase’e hazır JSON modeller)

## Çalıştırma

```bash
npm install
npm run dev
```

## Teknoloji
React 19 + Vite + TypeScript + Tailwind CSS + Lucide + dnd-kit
